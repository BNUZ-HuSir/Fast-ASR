## 本构建已通过

- Release 构建、格式检查、14 项 Rust 单元测试和 Clippy（警告视为错误）。状态机覆盖 500 ms 边界、499 ms 短按、阈值前组合、录音中取消、Ctrl / 右 Alt 排除及鼠标映射。
- 上游声明完整性检查及 5 项授权材料回归；不代表法律审计。
- xasr-self-test.json：六段中文、英文和混说 WAV 有输出，10 秒静音无输出。加载后工作集约 246 MiB，自测过程中约 264 MiB；该值来自无 GUI 诊断，不是所有设备上的上限。
- pipeline-probe.json：流式候选、长按预览、松键收尾、取消、快速松键、重启、重新加载和原生端点检查通过。
- hook-lifecycle.json：私有非活动桌面上实际安装/卸载键盘和鼠标钩子 5 次，两个监听相关线程完成清理，子进程退出码为 0，原生进程等待返回已结束。没有切换桌面、注入键鼠或打开麦克风。

上述三份 JSON 报告均为 0.3.6，哈希匹配本次可执行文件。验证脚本改为原生进程等待，并用独立短命子进程检查其等待逻辑。

## 尚未完成的桌面验收

当前会话保留此前六个 --hotkey-probe 退出未完成的进程：30580、53548、3376、73288、26476、72376。它们来自旧候选程序，不能仅依据进程名称判定为新构建。此前原生 WaitForSingleObject 仍超时；.NET HasExited 曾返回 true，不能证明完成退出。等待链未解析出具体依赖，根因未确立。

本版把钩子和输入重放移出界面线程，回调不执行 SendInput，并移除诊断的跨应用 AttachThreadInput；新的独立桌面生命周期检查已通过。但这不证明旧残留已清除，也不证明真实桌面所有交互下均已消除退出问题。

因此没有在当前桌面继续运行 hotkey-probe.json、input-probe.json、ui-probe.json 三项原生回归。真实 Alt+Tab / Alt+F4 / Alt+鼠标、跨应用自动填写、置顶及焦点交互仍待干净会话验收。本次没有打开真实麦克风。旧版通过报告不纳入本预览包，也不视为新构建的证据。

## 交付规则

本次以 Preview 交付，build-info.json 显式设置 desktop_regressions_verified=false 并列出缺测项。必须显式指定 --preview-without-desktop-tests 打包；已有正常验证打包 --require-ui 仍要求所有桌面报告哈希匹配。音频及私有桌面清理报告缺失或失败时，预览模式也会拒绝打包。

ZIP 完整性检查核对清单、文件哈希、模型及许可证、验证报告、源码包与中文路径解压，结果写入本地 reports/package-integrity-0.3.6.json。完整便携目录应保留模型、运行库和许可证，不能只复制 exe。

建议先正常退出旧版；若旧测试进程仍无法结束，保存工作并重启 Windows 后再试。旧版本和压缩包没有删除，正在运行的用户程序没有被终止。

## 识别与性能边界

仅 X-ASR-zh-en INT8 480 ms，权重总计 169,169,147 字节，CPU 推理；没有独立 VAD、Whisper 或 GPU 推理。六段 WAV 有输出不等于识别准确率达标，本轮没有 CER/WER 承诺。常用输入软件、真实讲话、噪声、口音、提权窗口及远程会话需用户实测。

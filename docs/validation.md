# Validation 0.3.1

验证日期：2026-10-23。本机 Intel i5-12600KF、32 GB RAM、Windows x64。全部为 CPU 推理；没有 GPU 推理上下文。权重文件大小、工作集、峰值工作集和私有提交量不是同一个指标。

## 自动验证范围

本轮本机检查、五份功能报告与独立目录构建全部通过。独立构建另用新生成的 exe 完成 X-ASR 六段 WAV 与静音自检。它验证可重新构建，不承诺不同路径产生字节一致的 exe。

- `scripts/verify.ps1 -IncludeUI`：格式、两个配置迁移/序列化单元测试、Clippy（警告视为错误）、两个模型各六段 WAV 与 10 s 静音、正式工作线程管线和桌面回归。报告包含版本和当前 exe 的 SHA-256，打包拒绝不匹配的报告。
- `xasr-self-test.json` / `turbo-self-test.json`：中文、英文、混说样本有识别输出，静音无文字。这是基本输出检查，没有与人工文本计算 CER/WER。
- `pipeline-probe.json`：按真实时间节奏回放 WAV；候选先于最终结果，样本没有丢失；候选后取消、重新开始、X-ASR → Turbo → X-ASR 及切回后文本一致性。
- `input-probe.json`：原生测试输入框中的中文、英文、数字与 emoji Unicode 输入，切换焦点后拒绝继续写入。自测不会向未确认的窗口输入。
- `ui-probe.json`：置顶标志双向切换、焦点保持、设置保存和恢复；复制后继续自动填写、换框保护、返回原框恢复、主动绑定；3,040 字符长文本保留、增高至 720 逻辑像素、滚动和清空收缩。模拟 UI busy 收尾状态时清空，检查取消命令及 Stopped 确认；真实管线取消另由 WAV 测试覆盖。

桌面自测需要交互式桌面。仅诊断代码临时关联前台输入线程，以激活自测拥有的窗口，随后立即解除；正式听写不会调用这一激活辅助函数。自测会短暂显示窗口、写入测试文字并使用剪贴板，请勿同时操作其他输入框。

## 构建和交付验证

- 独立目录 `.build/source-rebuild-0.3.1` 从明确的源码清单构建，重新解包固定版本的上游源码和运行库，重新编译 C++/Rust；仅复用已经校验的下载归档、模型与 Cargo 下载缓存，不复用原工程 target 或 Whisper 编译产物。结果见 `reports/source-rebuild-0.3.1.json`。
- `scripts/validate_package.py` 对便携包做 ZIP CRC、准确文件清单、逐文件 SHA-256、两模型齐全、旧权重和用户设置/历史缺席、源码构建材料及发布压缩包校验，并解压至中文目录。结果见 `reports/package-integrity-0.3.1.json`。
- 从中文路径运行解压后的程序，识别管线、Unicode 输入和 UI 回归最终通过，结果见 `reports/portable-run-0.3.1.json`。GitHub 工作流尚未运行，不能由本地测试推断远端 CI 通过。

## 适用边界

中文路径的交互式 UI 自测前两次未通过（一次无法获取前台焦点，一次返回原框/主动绑定检查未通过），第三次全部通过。此测试依赖前台焦点与消息时序，桌面应保持空闲；重试通过不能代替长期稳定性评估。当前工作区的完整五项检查在一次执行中通过。

没有自动打开麦克风；实际讲话、用户输入软件的兼容性由用户验收。未系统测量不同麦克风、口音、噪声或长时间录音，没有准确率保证。模型切换的正常路径已测试，推理错误时继续切换的恢复分支已做代码检查，尚未做专门故障注入。Turbo 在本机 CPU 上明显慢于实时，默认保持 X-ASR。上述五份功能报告随便携包位于 `docs/test-results/`；源码构建、仓库审核与交付验证报告保留在开发工作区 `reports/`。

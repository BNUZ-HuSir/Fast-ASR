# Fast ASR 0.3.4 交付评审

日期：2026-10-27。Windows 10/11 x64，CPU / AVX2，Preview。

## 变化与规则

Ctrl 单独长按 0.3 秒启动录音。X-ASR 在长按时实时经过 Silero VAD 和流式解码，UI 展示草稿，松开时才将确认结果送入输入框。Esc、Ctrl 组合键及清空取消草稿；60 秒自动收尾。短按和组合键转发原生事件。Turbo 仍按段识别，本次没有将其变成流式模型。

点击持续听写和长按说话共用一条录音/VAD/识别管线；VAD 不会自行开启麦克风。新增语音状态和概率显示，参数仍在下一次录音生效。0.3.3 的整段延后识别缓冲已移除。

## 验证范围

保留配置、键盘状态、许可证材料、双模型 WAV、输入与界面检查。原生 Ctrl 钩子探针测试 300 ms 阈值、重复按下、松开、短按、Ctrl+A、Esc 及无卡键/意外字符；其他 Ctrl 组合有状态测试。界面回归新增长按草稿可预览、按住不填写、松开提交、取消丢弃。实际管线要求 X-ASR 松开前已有候选事件，VAD 必须产生语音/静音遥测。同一 WAV 的原生 Silero 对照测试验证阈值、最短语音和停顿参数生效。

报告绑定版本及程序哈希。完整结果见 validation.md 和 docs/test-results/。自动测试不打开真实麦克风；实体键盘、输入法、真实讲话、Ctrl+鼠标手势和用户目标软件仍需试用。未新增模型或准确率评测，保留所有第三方许可证、模型卡、来源和用途说明。

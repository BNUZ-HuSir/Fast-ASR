# Fast ASR 0.3.3 交付评审

日期：2026-10-26。目标平台：Windows 10/11 x64，CPU / AVX2。此版本仍为 Preview。

## 交付变化

按住录音改为单独长按 Alt 0.5 秒开始，松开 Alt 后进行 VAD / ASR 并填写到原输入框。触发前不采集语音，单次最长 60 秒，Esc 取消。短按 Alt 转发为原生菜单按键；Alt 与其他键组合时转发原组合键，如果已开始录音则取消本次内容。先按住其他修饰键时不启动此手势。保留 Ctrl+Alt+空格按一次开始/停止，快捷键仍默认关闭。

键盘钩子只判断状态、转发按键和投递 UI 消息。音频和识别仍由原工作线程处理。转发失败时关闭快捷键并提示。0.3.2 的图钉、颜色图标、VAD 参数、两套模型及焦点保护保留。

## 验证范围

新增六项 Alt 状态测试，覆盖 500 ms 边界、重复按下、短按、Alt+Tab/F4/空格/字母、Ctrl+Alt/AltGr、Esc 和不可用状态。原生 Windows 钩子诊断在自有 EDIT 窗口发送标记的合成键盘事件，检查短按恢复、阈值、长按一次、松开提交、Alt+字母转发、Esc、无残留修饰键或输入字符。报告绑定版本与程序 SHA-256，打包时必须通过。

双模型 WAV 自检、实际 VAD 管线、长按提交/取消、快速松开、模型切换、Unicode 输入和界面回归均使用原诊断。自动验证不打开麦克风；实际键盘、输入法、真实讲话及目标软件兼容性仍需试用。交互诊断依赖前台焦点和 Windows 消息时序，详见 validation.md；不据此承诺所有应用或 Alt+鼠标手势兼容。

模型和来源未变；第三方许可证、模型卡和来源材料继续随包保留。Git 仅提交源码、脚本、文档和必要素材，不包含权重、运行库、用户数据或录音。完整本机结果见 validation.md 及随包 docs/test-results/。

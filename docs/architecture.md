# Architecture 0.3.3

Native Win32 Rust overlay uses WS_EX_NOACTIVATE. Protected Unicode SendInput commits final recognition results; streaming hypotheses stay in the preview. Clipboard, focus binding, deferred output and resize/scroll behavior share the existing UI path. Local JSON settings migrate retired Whisper Small choices to X-ASR without discarding other preferences.

The capture coordinator drains 16 kHz mono WinMM audio every ~8 ms. A separate inference thread owns exactly one recognizer. X-ASR accepts VAD-approved frames using sherpa-onnx 1.13.8 / ONNX Runtime CPU, greedy decoding and 480 ms model chunks. The application disables the model endpoint detector during normal capture; shared Silero VAD controls segment boundaries for both recognizers. Stop appends two seconds of synthetic zeros and signals input-finished immediately to flush model lookahead; these are not recorded or played. Silero VAD uses 512-sample frames, 320 ms pre-roll, hysteresis, configurable onset probability (0.2–0.8), minimum speech duration (64–512 ms), trailing silence and a 12 s segment bound. X-ASR receives accepted audio incrementally once the minimum speech duration is reached, while Turbo receives complete segments. Standalone decoder self-tests retain X-ASR built-in endpoint checks; the pipeline diagnostic exercises the actual shared-VAD coordinator.

Capture and inference exchange generation-tagged tasks; cancel invalidates queued output, and a new session resets recognizer state. Queue accounting tracks sample counts, stops capture on overload (10 s online / 90 s offline), and flushes remaining work. Model switching stops and drains the old session before destroying its decoder, then loads the replacement. A single shared VAD context remains alive across model switches so its ggml DLLs and process exception handler are not repeatedly unloaded and reinitialized. C++ bridges dynamically resolve local DLL functions; only the selected engine is instantiated. Model files are SHA-256 verified before loading. CPU inference uses up to six threads; no GPU context is created.

Portable layout: runtime/sherpa, runtime/whisper, models/xasr-480ms, models/ggml-large-v3-turbo-q5_0.bin, models/vad, samples, licenses. Full release bundles both models for offline use. Synthetic WAV replay exercises the same coordinator, partial/final delivery, stop, cancel/restart, and model-switch paths without opening a microphone.

The overlay measures all retained text and grows up to 720 logical pixels or monitor work-area bounds, then scrolls. A focus epoch prevents delayed text from entering an unrelated native edit control. Several custom/web editors may share a native HWND, so compatibility with user applications remains a user acceptance test.


The title-bar pin toggles HWND_TOPMOST / HWND_NOTOPMOST with SWP_NOACTIVATE, SWP_NOMOVE and SWP_NOSIZE. Its state is persisted as Settings.topmost; old settings default to pinned. The UI regression clicks both states, checks the actual WS_EX_TOPMOST flag, original input focus and settings roundtrip.

During cancellation the UI ignores partial/final events until the worker acknowledges Stopped, so already-forwarded events cannot repopulate cleared text. Cancel remains enabled during decoding. Generation IDs invalidate pending inference tasks; if a decoder error occurs while switching, the coordinator still advances to the requested model.

Release packaging uses a list populated only by deliberate copies, never a recursive inventory of an existing output directory. Every required diagnostic has to pass and match both the package version and executable SHA-256. Archive integrity, exact inventory and separate release SHA256SUMS are verified after packaging.

The optional hold shortcut uses a WH_KEYBOARD_LL hook and a standalone-Alt state machine. Alt down is deferred for 500 ms; a 50 ms UI timer starts capture at or after that threshold. A short tap replays the balanced native Alt events. Another key replays Alt plus that key in order and cancels pending/active hold recording, preserving native keyboard combinations; already-held modifiers bypass the gesture, including Ctrl+Alt/AltGr. Alt release requests Stop; Escape cancels. Injected events are ignored by the production hook to avoid replay loops. The hook performs no audio/inference work, and replay failures disable the shortcut with a UI notice. Ctrl+Alt+Space toggle remains registered separately through RegisterHotKey with MOD_NOREPEAT. The pending-start state allows Stop to queue even before asynchronous capture startup is acknowledged. While holding, audio is buffered without ASR tasks, bounded to 60 seconds (3.84 MB of f32 PCM); on release it is passed through the same VAD/inference pipeline. Escape drops buffered audio and invalidates pending results. Both modes are disabled while the settings window is open. Legacy settings without a mode retain toggle; existing hold mode uses the new Alt gesture. New installations leave shortcuts disabled.

The pin is drawn as a scalable GDI icon. The microphone action uses a green microphone at rest, a red stop square during capture, and a waiting glyph during inference. Colors and icons derive from recording/pending/processing state without activating the target window.

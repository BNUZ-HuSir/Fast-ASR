# Fast ASR 0.3.6 Preview 发布评审

日期：2026-10-28。开发者：Elza。

## 本次交付

默认手势为单独按住左 Alt 至少 500 ms，按住时使用 X-ASR 流式预览，松开后收尾并向绑定输入框填写。右 Alt / AltGr 和 Ctrl 不触发。只保留 X-ASR-zh-en INT8 480 ms；没有独立 VAD。便携包自带模型和 CPU 运行库，不需要 Python 或重新下载模型。

短按左 Alt 恢复原生按键；录音长按抑制 Alt 菜单边沿。Alt+Tab、Alt+F4、Alt+Space、Alt+Enter 等键盘组合恢复 Alt 与第二键的顺序；录音若已开始，取消未提交草稿。录音开始后的 Alt+Esc 用于取消；阈值前保留原组合。Alt+鼠标按下或滚轮转发修饰键和鼠标动作，取消已开始的草稿；移动不取消。已经按住其他键或鼠标按钮时不进入录音手势。

阈值由 0.3 秒增至 0.5 秒，给组合键留出更多准备时间。超过阈值后才按第二键，仍可能先进入录音，再取消并转发组合，不能消除所有误触。麦克风变红后再说话；没有预录。

## 退出路径改造

键鼠钩子由独立的消息线程拥有，不再安装到界面线程。钩子回调只更新手势并排队，SendInput 在另一个线程执行；转发积压时按顺序排队后续实体键边沿与鼠标按钮/滚轮，避免松键越过延迟的按键。启动和退出等待设有时限；正常退出显式卸载两个钩子、关闭队列并等待工作线程。诊断不再调用 AttachThreadInput 绑定其他应用的输入队列。

新增私有桌面生命周期检查：不切换用户桌面、不注入按键、不打开麦克风，在独立子进程中实际安装和卸载键鼠钩子五次，并由父进程确认 Windows 原生进程等待返回已结束。该检查覆盖监听清理，不代替真实 Alt 组合、输入填写或 UI 验证。

## 预览版验证边界

本轮旧诊断曾留下六个退出未完成的进程。根因尚未确立，代码改造不能证明旧残留已被清除，也不能据此宣布原问题彻底修复。当前会话暂停原生键鼠、自动填写和 UI 回归；不复用 0.3.5 或较早 0.3.6 二进制的报告。

预览包只纳入哈希匹配的新构建音频管线、模型自测和私有桌面清理报告。build-info.json 明确标记 release_channel=preview、desktop_regressions_verified=false 以及待完成的三项桌面回归。完整验证打包仍使用 --require-ui；预览打包必须显式使用 --preview-without-desktop-tests，不能把缺测项记为通过。

建议先正常退出旧版；若仍有无法结束的旧测试进程，保存工作并重启 Windows 后再试用。没有自动终止用户程序、打开真实麦克风、删除旧包或重启系统。实测兼容性由用户在常用输入软件中验收。

# Fast ASR 0.3.2 交付评审

日期：2026-10-26。目标平台：Windows 10/11 x64，CPU / AVX2。此版本仍为 Preview。

## 交付变化

- 图钉图标切换置顶，不激活目标输入框；选择随设置保存。
- 就绪时绿色麦克风、采集时红色停止图标、处理时等待图标。
- 两种 ASR 使用共同的 Silero VAD，公开阈值、最短语音、停顿参数。默认 0.5 / 128 ms / 600 ms。
- Ctrl+Alt+空格可选择按住录音、松开识别，或原有的按一次切换。新安装默认关闭；旧版已启用的快捷键保留切换模式。
- 按住录音期间只缓冲音频，松开后进行 VAD 和识别，60 秒自动收尾；Esc 丢弃未提交内容。
- 下载脚本同时准备共享 VAD，并保留所有既有上游许可证和用途说明；模型和运行库不进入 Git。

## 验证范围与边界

具体结果与当前程序 SHA-256 记录在随包的五份功能诊断中。实际麦克风、不同输入法、各种目标软件、实体键盘长按及噪声环境仍需用户实际试用。WAV 回放代替自动开启麦克风。VAD 参数调整不构成降噪或说话人隔离；Turbo 在 CPU 上仍然较慢。

模型和来源未变，本次未新增第三方模型。保留第三方原始许可证、模型卡、来源及哈希证据，不对模型训练数据权利链作保证。项目用途说明不改变上游授权。

## 本机验收结果

构建、格式、5 项 Rust 测试、5 项授权材料测试、Clippy、五份功能报告和模型文件校验全部通过。报告包含两模型的长按提交、取消、快速松开、敏感 VAD 静音和切换回放。界面截图更新为本版本。

交付时另外运行便携包 CRC、文件清单及逐文件 SHA-256 校验，并从中文路径启动解压后的程序执行诊断；原始记录位于工作区 reports/。源码发布不包含模型、运行库、设置或录音。

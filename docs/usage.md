# Fast ASR 0.3.4 使用说明

![悬浮窗](images/overlay.png)

## 开始听写

1. 完整解压便携包，双击 `FastASR.exe`。保留同目录的 `runtime/` 与 `models/`。
2. 等待显示“就绪”，点击要填写的输入框，再点击悬浮窗左侧麦克风。
3. 说中文、英文或中英混合句子。候选文字在悬浮窗预览；停顿后，确认结果自动写入绑定的输入框。不会自动按回车或发送消息。
4. 再点麦克风停止录音并收尾；`Esc` 取消当前录音和未完成识别。

启动时不录音。VAD / 端点检测只在手动开始录音后工作。快捷键默认关闭，需要时在设置中选择 Ctrl 长按或 Ctrl+Alt+空格切换；无法启用时可继续使用麦克风按钮。

## 常用按钮

- **图钉图标**：控制悬浮窗是否保持在其他窗口上方；重启后保留选择，不抢目标输入框焦点。
- **模型名称**：切换 X-ASR / Turbo，也可在设置中选择。切换完成后重新点击麦克风开始。
- **复制**：优先复制未填入的文字，否则复制本次文本；复制后仍可继续自动填写。
- **填写**：先点击目标输入框，再点此按钮，主动绑定新目标；没有待填文字时也可绑定。
- **清空**：取消本次录音和未完成识别，清空预览及待填文字，窗口恢复高度。
- **设置**：选择麦克风、识别模型、VAD 参数、停顿时间和快捷键。标题栏右侧可隐藏悬浮窗，托盘菜单可重新显示或退出。

文字增多时窗口自动拉高，达到屏幕/高度限制后用滚轮查看。复制保留完整文本。

## 选择模型

默认 **X-ASR-zh-en INT8 480 ms 流式**，适合本项目的中英文日常输入。三个权重合计约 169 MB，本机实际管线（含 VAD）峰值工作集约 272 MiB。480 ms 是模型块配置，实际填写还要等待停顿和处理。

可选 **Whisper Large-v3-Turbo Q5_0** 已随完整版提供，权重约 574 MB；它采用语音分段后识别。在本机 CPU 上，3.9 秒音频单次解码约 19.7 秒，峰值工作集约 757 MiB，适合对照测试。Whisper 仍是多语言模型，不能保证只输出中英文。

两个模型使用 CPU，只驻留当前选择的识别模型，无需 Python、CUDA 或单独下载权重。文件大小与运行内存不同；详细条件见 [验证记录](validation.md)。需要支持 AVX2 的 Windows 10/11 x64 电脑，以及可写的软件目录。

## 输入框与数据

焦点离开绑定的原生控件时暂停填写，回到原控件后恢复；要换输入框请主动绑定。高权限软件可能拒绝模拟输入；部分网页或自定义控件共享原生句柄，需在自己的目标软件中测试。请勿在敏感字段开启听写。

正常使用不上传语音，不保存录音或转写历史。设置保存在 `data/settings.json`；主动运行诊断才生成 `reports/`。旧 Small 模型已退出新版模型列表和交付包，旧设置会迁移为 X-ASR。

0.3.4 为 Preview，尚未签名；准确率与目标软件兼容性以实际使用为准。下载包可用同版本 `SHA256SUMS` 检查。反馈时提供版本、模型、Windows/CPU、目标软件与重现步骤，避免上传个人对话和敏感内容。

## VAD 与按住录音

设置中的 VAD 适用于 X-ASR 和 Turbo：

| 参数 | 默认 | 调整方式 |
| --- | --- | --- |
| 语音阈值 | 0.5 | 0.2–0.8；越低越敏感。轻声漏检时调低，背景声误触发时调高。 |
| 最短语音 | 128 ms | 可选 64 / 128 / 256 / 512 ms；提高可过滤短促杂音，也可能漏掉很短的词。 |
| 停顿后填写 | 600 ms | 可选 400 / 600 / 1000 ms；提高可减少句中停顿导致的分段。 |

VAD 判断声音是否像语音，不能区分说话人，也不能保证消除电视、人声或所有噪音。参数在下一次开始录音时生效。鼠标点击麦克风后实时听写，停顿后填写；这不是开机自动常驻监听。

在“设置 → 全局快捷键”选择“Ctrl 长按 0.3 秒录音 · 松开后填写”并保存。先点击目标输入框，单独按住 **左或右 Ctrl 至少 0.3 秒**，等麦克风变红后说话；松开 Ctrl 停止采集，提交已确认文字并收尾。识别时请保持目标焦点。

X-ASR 在长按期间就经过 VAD 和流式 ASR，候选与确认文字在悬浮窗实时预览；只将写入目标输入框的动作延后到松开。取消会丢弃本次未提交草稿。Turbo 仍按语音段识别，按住时有停顿会触发段解码，但它不支持 X-ASR 式的实时候选。触发前 0.3 秒不采集音频，单次最长 60 秒。

短按 Ctrl 保留原按键行为。Ctrl+C/V/A/Z、Ctrl+Tab 等组合键转发原组合；如果已开始长按录音，会取消本次内容后转发，避免误提交。先按住其他修饰键再按 Ctrl 不启动录音。真实 Windows 合成事件覆盖短按、长按、松开、Ctrl+A 和 Esc；其他组合有状态测试，实体键盘、输入法及目标应用请实际试用。Ctrl+鼠标手势没有专门拦截支持。

“Ctrl+Alt+空格 · 按一次开始/停止”保留连续实时听写；旧版切换模式保持原行为，旧版长按模式升级为 Ctrl 0.3 秒。快捷键默认关闭，设置页打开时不启动录音。

## 三者如何配合

| 功能 | 谁打开录音 | 识别与预览 | 何时填写 |
| --- | --- | --- | --- |
| 点击麦克风 | 点击开始，再点停止 | X-ASR 流式；Turbo 分段 | VAD 判定停顿后填写，停止时收尾 |
| Ctrl 长按 | 长按满 0.3 秒，松开停止 | X-ASR 流式；Turbo 分段 | 松开后统一填写，取消则丢弃 |
| VAD | 不单独打开麦克风 | 两个入口共用的语音过滤和分段 | 参与确定语音段结束，服从所选入口的提交规则 |

本版没有自行常驻监听、检测到声音就开启麦克风的模式。需要免按键连续听写时，点击麦克风一次，VAD 随后持续工作，直到手动停止。

## 如何确认 VAD 在工作

1. 选择 X-ASR，保存设置后点击麦克风开始。
2. 安静时标题应显示“等待语音”；底部的 `VAD 0.02 / 0.50` 表示当前语音概率与配置阈值，不是音量或识别准确率。
3. 说完整句子，观察标题切换到“检测到语音”、语音概率上升，预览出现；停顿后文字写入目标框。
4. 将“停顿后填写”从 400 ms 改为 1000 ms，保存并重新开始录音，对照句子结束后等待时间。实际填写还包含模型推理耗时。
5. 轻声漏检可降低阈值；背景声音误触发可提高阈值或最短语音。VAD 不能区分用户与其他人的讲话，正常连续说话时不一定容易看出不同阈值的差异。

长按模式同样显示 VAD 状态，但暂停说话时只结束识别段，不会提前向输入框填写。使用滞回判断避免状态抖动，最短语音过滤也会影响何时开始识别。

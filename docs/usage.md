# Fast ASR 0.3.6 使用说明

完整解压便携包，双击 FastASR.exe，等状态变为“就绪”。程序初始不打开麦克风。首次使用默认选择 左 Alt 长按 0.5 秒；升级时保留已有快捷键选择。

## 长按输入

点击要输入的控件，单独按住左 Alt。至少 0.5 秒且麦克风变红后开始说话，悬浮窗会逐步显示识别内容。松开左 Alt 会停止录音、处理剩余音频，再将文字填入原输入框。按住期间的断句结果暂存，不会提前写入目标框。

Esc 取消本次未填写内容；录音期间按 Alt+Tab 等组合键或 Alt+鼠标点击/滚轮也会取消本次草稿，并恢复组合键原本行为。短按左 Alt 不启动识别。触发前没有预录，最长单次 60 秒。已有其他键或鼠标按钮按住、应用忙碌和设置打开期间，不启动长按录音。

短按左 Alt 保留菜单行为；单独长按录音松开后不激活菜单。右 Alt / AltGr 不触发录音。Alt+Tab、Alt+F4、Alt+Space、Alt+Enter、Alt+Shift 等组合恢复原组合，已启动的草稿取消；录音已触发时 Alt+Esc 专用于取消，不执行原生切窗。Alt+拖动通过转发鼠标按下前的 Alt 状态保留操作，单纯移动鼠标不打断录音。使用提权窗口、游戏或远程桌面时需单独确认兼容性。

将阈值设为 0.5 秒，比 0.3 秒多留出 0.2 秒组合键准备时间。若超过 0.5 秒才按第二键，仍会先开始录音，再取消并转发组合键；不能保证消除误触。麦克风变红后再说话，触发前没有预录。

## 点击输入

先点击目标框，再点击绿色麦克风进入连续输入。X-ASR 持续预览，模型检测到句末停顿后填写；点击红色停止按钮处理最后一句并结束。长按与点击共用同一条录音管线，不会同时打开两路麦克风。点击录音过程中不用持续按键。

本版没有 VAD 模型、VAD 参数或免按键自动唤醒。X-ASR 自身端点检测采用固定约 600 ms 的尾部静音条件；实际显示延迟还包含模型前瞻和推理时间。

## 简单设置

设置显示固定的 X-ASR 模型名称，只提供麦克风和全局快捷键选择。快捷键可以关闭、使用默认 左 Alt 长按，或选择 Ctrl+Alt+空格切换开始/停止。保存后生效。页脚标注“开发者：Elza”。

图钉按钮青绿色为置顶，灰色为未置顶；切换会保存，并保持输入框焦点。就绪麦克风为绿色，录音停止按钮为红色，处理中为等待图标。

## 复制、填写与长文本

“复制”复制待填写文字，若无待填写文字则复制本次完整转写。复制后自动填写仍可继续。焦点离开原框会暂停写入；返回后恢复。要换输入框，请点击新框，再点“填写”。“清空”清空本次文本并取消录音。

文字增多时窗口自动拉高，到高度上限后可用滚轮查看。复制可以取得完整文字。不会自动按回车，也不保存录音或转写历史。

首次使用建议在普通文本编辑器试录中英文，再测试自己常用的软件。权限更高的窗口可能拒绝模拟输入，部分网页与自定义控件的输入保护存在边界，详见 SECURITY.md。应用兼容性与实际讲话由用户验收。

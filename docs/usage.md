# Fast ASR 0.3.3 使用说明

![悬浮窗](images/overlay.png)

## 开始听写

1. 完整解压便携包，双击 `FastASR.exe`。保留同目录的 `runtime/` 与 `models/`。
2. 等待显示“就绪”，点击要填写的输入框，再点击悬浮窗左侧麦克风。
3. 说中文、英文或中英混合句子。候选文字在悬浮窗预览；停顿后，确认结果自动写入绑定的输入框。不会自动按回车或发送消息。
4. 再点麦克风停止录音并收尾；`Esc` 取消当前录音和未完成识别。

启动时不录音。VAD / 端点检测只在手动开始录音后工作。快捷键默认关闭，需要时在设置中选择 Alt 长按或 Ctrl+Alt+空格切换；无法启用时可继续使用麦克风按钮。

## 常用按钮

- **图钉图标**：控制悬浮窗是否保持在其他窗口上方；重启后保留选择，不抢目标输入框焦点。
- **模型名称**：切换 X-ASR / Turbo，也可在设置中选择。切换完成后重新点击麦克风开始。
- **复制**：优先复制未填入的文字，否则复制本次文本；复制后仍可继续自动填写。
- **填写**：先点击目标输入框，再点此按钮，主动绑定新目标；没有待填文字时也可绑定。
- **清空**：取消本次录音和未完成识别，清空预览及待填文字，窗口恢复高度。
- **设置**：选择麦克风、识别模型、VAD 参数、停顿时间和快捷键。标题栏右侧可隐藏悬浮窗，托盘菜单可重新显示或退出。

文字增多时窗口自动拉高，达到屏幕/高度限制后用滚轮查看。复制保留完整文本。

## 选择模型

默认 **X-ASR-zh-en INT8 480 ms 流式**，适合本项目的中英文日常输入。三个权重合计约 169 MB，本机实际管线（含 VAD）峰值工作集约 273 MiB。480 ms 是模型块配置，实际填写还要等待停顿和处理。

可选 **Whisper Large-v3-Turbo Q5_0** 已随完整版提供，权重约 574 MB；它采用语音分段后识别。在本机 CPU 上，3.9 秒音频单次解码约 20.3 秒，峰值工作集约 757 MiB，适合对照测试。Whisper 仍是多语言模型，不能保证只输出中英文。

两个模型使用 CPU，只驻留当前选择的识别模型，无需 Python、CUDA 或单独下载权重。文件大小与运行内存不同；详细条件见 [验证记录](validation.md)。需要支持 AVX2 的 Windows 10/11 x64 电脑，以及可写的软件目录。

## 输入框与数据

焦点离开绑定的原生控件时暂停填写，回到原控件后恢复；要换输入框请主动绑定。高权限软件可能拒绝模拟输入；部分网页或自定义控件共享原生句柄，需在自己的目标软件中测试。请勿在敏感字段开启听写。

正常使用不上传语音，不保存录音或转写历史。设置保存在 `data/settings.json`；主动运行诊断才生成 `reports/`。旧 Small 模型已退出新版模型列表和交付包，旧设置会迁移为 X-ASR。

0.3.3 为 Preview，尚未签名；准确率与目标软件兼容性以实际使用为准。下载包可用同版本 `SHA256SUMS` 检查。反馈时提供版本、模型、Windows/CPU、目标软件与重现步骤，避免上传个人对话和敏感内容。

## VAD 与按住录音

设置中的 VAD 适用于 X-ASR 和 Turbo：

| 参数 | 默认 | 调整方式 |
| --- | --- | --- |
| 语音阈值 | 0.5 | 0.2–0.8；越低越敏感。轻声漏检时调低，背景声误触发时调高。 |
| 最短语音 | 128 ms | 可选 64 / 128 / 256 / 512 ms；提高可过滤短促杂音，也可能漏掉很短的词。 |
| 停顿后填写 | 600 ms | 可选 400 / 600 / 1000 ms；提高可减少句中停顿导致的分段。 |

VAD 判断声音是否像语音，不能区分说话人，也不能保证消除电视、人声或所有噪音。参数在下一次开始录音时生效。鼠标点击麦克风后实时听写，停顿后填写；这不是开机自动常驻监听。

在“设置 → 全局快捷键”选择“Alt 长按 0.5 秒录音 · 松开后识别”并保存。先点击目标输入框，单独按住 **Alt 至少 0.5 秒**，等麦克风变红后说话；松开 Alt 即停止采集，再进行 VAD 分段和 ASR，结果填写到原输入框。前 0.5 秒仅判断按键，不采集语音。识别时请保持目标焦点。此模式在按住期间不产生识别预览，单次最长 60 秒，缓冲音频仅保存在内存中。Esc 可取消。

短按 Alt 保留原菜单操作。按 Alt 的同时按其他键，会转发原组合键，不触发录音；已经长按开始录音后再按其他键，会取消这次录音并转发组合键。先按住 Ctrl 再按 Alt（包括 AltGr）也不会启动录音。Alt+Tab、Alt+F4 的判断经过状态测试；真实 Windows 合成事件覆盖短按、长按、松开、Alt+字母和 Esc，具体输入法及目标应用请实际试用。

“Ctrl+Alt+空格 · 按一次开始/停止”保留连续实时听写；旧版已启用的切换模式保持原行为，旧版按住模式升级为 Alt 长按。快捷键被其他软件占用时会提示并停用，可继续使用鼠标按钮。设置页打开时快捷键不启动录音。

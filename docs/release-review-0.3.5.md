# Fast ASR 0.3.5 发布评审

日期：2026-10-27。维护者 / 开发者：Elza（BNUZ-HuSir）。发布阶段：Preview。

## 变更范围

按当前需求移除独立 VAD 和所有相关设置、状态。仅构建、加载和打包 X-ASR 中英文 480 ms INT8；Whisper Turbo 菜单、模型与运行库退出新包。音频直接进入 X-ASR 在线识别器，连续输入使用原生端点断句。

首次使用默认 Ctrl 长按至少 300 ms。长按期间流式预览，松键填写；取消丢弃本次未提交草稿。已有用户的显式快捷键设置保留，旧模型配置迁移为 X-ASR。设置只保留麦克风和快捷键，增加“开发者：Elza”。置顶改为圆角图标按钮，选中使用青绿色边框与填色，继续保持焦点和保存偏好。

## 评审重点

- 保留鼠标连续输入与 Ctrl 长按共用单条录音管线；默认启用快捷键不等于启动录音。
- 去掉外部 VAD 后，模型原生端点需要独立覆盖连续两句、收尾、取消、重启和静音检查。
- 简化设置验证开发者文案、快捷键选择及旧模型 / VAD 选择器缺席；置顶仍验证切换、持久化和焦点。
- 新包需验证只有 X-ASR，且没有 Whisper / VAD 二进制、用户设置或历史；源码包需可独立构建。
- 保留全部上游声明和原文，历史材料注明用途，不将“学习分享”写成覆盖上游的限制。

验证结果及本机性能见 docs/validation.md 和随包 docs/test-results/。完整压缩包包含模型；源码 Git 不含权重或运行库。旧版本文件不自动删除。

## 验收边界

程序仍为未签名的 Windows Preview。自动检查不打开实际麦克风，不代表不同口音、噪声和所有输入软件的准确率或兼容性；这些由用户试用验收。识别候选只在悬浮窗显示，确认结果才填入控件。没有后台免按键唤醒。
